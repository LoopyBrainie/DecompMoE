## Question

从 K, V 矩阵提取低维结构签名 C 的算子选什么？

**Complexity Budget 硬约束**：Decode 阶段必须 `O(d_c · d_k)` 或 `O(d_c)` 时间 + `O(d_c)` 空间 per token

候选：
- **(L) 低秩可学习投影**：`C = P · vec(KV^T)`，P ∈ R^{d_c × d_k·d_v}，参数量大但完全可微
- **(P) 幂迭代 (Power Iteration)**：取 leading singular vector，每 token k 次迭代
- **(F) 2D-FFT/DCT 低频截断**：对 KV^T 做 2D 频域变换，取前 d_c 个低频系数（但 2D FFT 是 O(d_k·d_v·log)，可能超 budget）
- **(S) 截断 SVD**：用 top-d_c singular vector（每 token 做 SVD 太贵）
- **(K) K^T V 矩阵的统计量**：trace、范数、sum、max eigenvalue
- **(M) 混合**：频域 + 可学习投影（如 DCT 后接线性层）

**关键问题**：在 d_c 维下 budget 严格成立吗？幂迭代收敛需要几步？

## Resolution (v2 — 球面归一化贯穿全程)

**关键修订**：原 RMS Standardize (Step 2) 被替换为 Per-Head Spherical Projection。**两次 L2 归一化**保证几何一致性：
1. 投影后立即 per-head 归一化（每个 head 的签名在球面）
2. Mean 聚合后再归一化（聚合结果仍在球面）

### Pipeline（球面归一化贯穿全程）

**Step 1 — Per-Head 低秩投影**
```
z_t^{l,h} = W_{l,h}^K · k_t^{l,h} + W_{l,h}^V · v_t^{l,h} + b_{l,h} ∈ R^{d_c}
```

**Step 2 — Per-Head Spherical Projection**（替换原 RMS）
```
C_t^{l,h} = z_t^{l,h} / (||z_t^{l,h}|| + ε) ∈ S^{d_c-1}
```

**Step 3 — Cross-Head Mean**
```
z̄_t^l = (1/H_kv) · Σ_h C_t^{l,h}    (球面内点，可能不在球面)
```

**Step 4 — Final L2 Norm**
```
C_t^l = z̄_t^l / (||z̄_t^l|| + ε) ∈ S^{d_c-1}
```

### 复杂度复核（v2 简化）

| 步骤 | Per-token cost | 空间 |
|---|---|---|
| Step 1 投影 | O(H_kv · d_c · d_k) | O(H_kv · d_c) |
| Step 2 Per-Head Norm | O(H_kv · d_c) | O(1) |
| Step 3 Mean | O(H_kv · d_c) | O(d_c) |
| Step 4 Final Norm | O(d_c) | O(d_c) |
| **总计** | **O(H_kv · d_c · d_k)** | **O(d_c)** ✅ |

### 几何意义

- **C_t^l ∈ S^{d_c-1} 严格单位球面**——A3-1 锁定的强先验
- A4-1 距离度量几乎必然要求 `c_i^l ∈ S^{d_c-1}`（与 C 同空间）
- 各向同性退化：`||C - c_i||² = 2(1 - C^T c_i)`（球面 + 单位范）
- spec 全文假设 C 与 c_i 同在 S^{d_c-1} 上
