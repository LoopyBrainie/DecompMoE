## Question

训练时常见数值地雷的处理策略：

地雷清单：
- **σ → 0**：单专家硬分配，梯度消失，所有 token 路由到同一专家
- **σ → ∞**：所有专家权重趋同，无专业化
- **C 出现 NaN**：SVD / 幂迭代可能数值不稳定
- **某专家 100% 占用**：expert collapse
- **梯度爆炸**：router logits 过大导致链式反应

候选策略：
- **(C) Gradient Clipping**：全局 grad clip
- **(S) σ 范围硬约束**：`σ ∈ [σ_min, σ_max]`，softplus + offset
- **(R) Reinit / Reset**：监测到坍缩时重置该专家
- **(N) NaN 检测 + skip step**
- **(E) Entropy regularization**：惩罚路由熵过低
- **(D) Dead expert detection + resurrection**

**关键问题**：哪些是 inline safeguard（每 step 跑），哪些是 periodic check（每 N step 跑）？

## Resolution

**锁定 5 项 operational safeguard + 标准执行顺序**

### 标准执行顺序

```
Backward → clip_grad_norm_(1.0) → optimizer.step() → L2_norm_(c)
```

**数学依据**：autograd 在 L2 归一化前向图中隐式完成切空间投影，标准顺序等价一阶黎曼 SGD。

### ① Global Gradient Clipping

- 阈值：`grad_clip = 1.0`（PyTorch 标准）
- 覆盖：所有可学习参数 (W^g, W^u, W^d, W^K, W^V, b, γ, c_i)
- 球面参数在 step 后 L2 归一化（保持 c_i ∈ S^{d_c-1}）

### ② NaN Detection & Escalation

| 连续 NaN 步数 | 响应 |
|---|---|
| 1 | Skip + `zero_grad()` + AMP scaler decay |
| 3 | LR ÷ 10 |
| 10 | **Halt training**, alert user |

- 检测范围：`C, c_i, logit, W^g, W^u, W^d`（主要可学习 tensor）
- AMP scaler 路径：自动处理 fp16 underflow

### ③ Dead Expert Splitting Resurrection（Split-and-Decay）

- **触发**：`f_i^avg < 1/128` 持续 200 steps
- **目标**：`j* = argmax f_j^avg`（当前最忙 expert）
- **分裂动作**：
  ```
  c_i ← Normalize(c_{j*} + ε),      ε ~ N(0, 0.05² I)
  β_i ← 0.85 × β_{j*}               (继承同量级)
  β_{j*} ← 0.85 × β_{j*}             (协同衰减——j* 自身也松绑)
  W_i ← W_{j*} + N(0, 10^-4 I)        (继承主权重 + 微扰)
  ```
- **限流**：每 1000 steps 最多 1 次
- **设计哲学**：新 expert 是 j* 的"子类"，保留其语义；j* 自身衰减避免被进一步压榨

### ④ β Saturation Guard

| 状态 | 阈值 | 响应 |
|---|---|---|
| Warning | `β_i > 30.4` (95% β_max) | log warning |
| Action | `>50%` 专家 `β_i > 28.8` (90% β_max) | Global LR ÷ 2 |

- 不强制 `β ≤ β_max`——允许偶发越界（Phase 3+ 常见）
- 信号触发而非硬约束

### ⑤ Loss Spike Defense（A6b 接口）

- **仅 Phase 3+ 启用**（Phase 1-2 还在探索，loss 波动是 normal）
- 阈值：`L_task > 2.5 × EMA(L_task)`（指数滑动平均）
- 响应：`LR × 0.8`（温和调整，非 0.1 激进降速）

### Inline vs Periodic

| 类别 | 频率 | 项目 |
|---|---|---|
| **Inline**（每 step） | 100% | ① Global Grad Clip, ② NaN 检测 |
| **Periodic**（每 N step） | 100 / 200 / 1000 | ③ f_i 监控 (100), ④ β 监控 (200), ③ Resurrection 限流 (1000) |
| **Conditional** | on-trigger | ② Escalation, ④ LR ÷ 2, ⑤ LR × 0.8 |
