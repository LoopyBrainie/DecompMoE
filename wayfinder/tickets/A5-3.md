## Question

核心超参（num_experts N, top-k, C 维度 d_c, σ_init, expert hidden dim）之间的比例关系如何定？

**只定选择策略，不定具体数值**

候选 scaling 范式：
- **(S) Standard MoE scaling**：N 随总参 O(N · d_expert) 线性扩，k = 2 固定
- **(F) Fine-grained scaling**：N 极大，d_expert 极小（如 DeepSeek 256 routed + 1 shared, top-8）
- **(C) C 维度 scaling**：d_c 随总参 log scaling，σ_init 随 d_c 缩放
- **(A) 联合 scaling**：N · d_expert · d_c 三者联合优化（实验密集型）

**关键问题**：
- 总参数预算、激活参数预算、推理 FLOPs 预算分别给多少？
- d_c 怎么定（经验 vs 公式 vs 搜索）？
- σ_init 设多少（覆盖范围 / 簇半径统计量）？

## Resolution

**锁定：(S) Standard MoE Scaling（Mixtral 风格）+ 以下 MVP 默认值**

### 1. Dimension Scaling（4070 MVP 终态）

| 超参 | 终态值 | 代数含义与约束理由 |
|---|---|---|
| `d_model` | **1024** | 主表征空间维度 |
| `d_ffn` | **2048** (per expert) | SwiGLU 标准 (2 × d_model) |
| `d_c` | **16** | KV 结构签名超球面 (S^15) |
| `N_e` | **16** | 每层专家数 |
| `k` | **2** (A4-2 已锁) | 单 Token 选通 |
| `L` | **4** | 深度网络层数（控制显存） |
| `β_0` (Phase 1 init) | **≈ 1.0** (A3-2 锁 γ_init ≈ -3.5) | 宽门控探索 |
| `β_target` (Phase 3) | **≈ 16** | 1/e 半径 20.36° < Voronoi (N_e=16 重新计算) |

### 2. Budget & Ratios（d_model = 1024, L = 4）

| 指标 | 数值 | 公式 |
|---|---|---|
| **Total Params** | **~452 M** | Embed 32.8M + Attn 16.8M + 16·3·1024·2048/layer · 4 layer |
| **Active Params** | **~100 M** | Embed 32.8M + Attn 16.8M + 2·3·1024·2048/layer · 4 layer |
| Params per expert | **~6.3 M** | `3 · d_model · d_ffn = 3 · 1024 · 2048` |
| **Capacity Factor** | **~4.5x** | Total / Active = 452 / 100 |
| **显存峰值 (BF16+8bit)** | **~6.8 GB** | B=1, S=1024，留 ~5.2GB 安全裕度（4070 8GB 可跑） |
| **Activation FLOPs / token** | **~50.4 M** | L · k · 3 · d_model · d_ffn (MoE) = L · 3 · d_model · 4096 (Dense) |

**vs 原 spec (d_model=2048, N_e=64, Total ~1.076B)**：缩小到 4070 可跑规模。

### 3. Spherical Geometry Bounds（球面覆盖自洽性，N_e=16 重新计算）

| 量 | 值 | 含义 |
|---|---|---|
| `θ_Voronoi` | **~52°** (估算) | 16 个点在 S^15 上的等距划分上界 |
| `θ_1/e` (Phase 3, β=16) | **20.36°** | `arccos(1 - 1/β)` |
| `g_boundary` | **~0.001** (估算) | Voronoi 边界处 gate 值（β=16, d_V=1） |
| `θ_expl` (Phase 1, β=1.0) | **90.00°** | 半球级探索 |

**自洽性**：20.36° < 52°，Phase 3 领地能完全覆盖 S^15。但 N_e=16 时 Voronoi 角度大，相邻 expert tail overlap 较 N_e=64 时弱——**c_i 分化学习更重要**。

### 4. Active FLOPs 严格对齐（与 Dense baseline 1:1）

```
Dense FFN FLOPs = L · 3 · d_model · d_ffn_dense = 4 · 3 · 1024 · 4096 = 50.4M / token
MoE 激活 FLOPs   = L · k · 3 · d_model · d_ffn_expert = 4 · 2 · 3 · 1024 · 2048 = 50.4M / token
```

✓ **1:1 严格对齐**——MoE 激活 FLOPs = Dense 全 FFN FLOPs（这是 A8-1 控制变量基础）

### 5. β 退火 Schedule（沿用 A6b-1 锁的分段线性）

- Phase 1: `β_0 ≈ 1.0` (γ ≈ -3.5)
- Phase 2: `β` 1.0 → 4.0 linear ramp
- Phase 3: `β` 4.0 → 16.0 linear ramp
- Phase 4: `β ∈ [1.0, 32.0]` free
- 球面几何对 N_e=16 仍自洽（20.36° < 52°）

### 6. Scaling 关系（4070 MVP spec 全文遵循）

- `d_ffn` per expert = 2048 = `2 × d_model`
- `d_c` = 常数 16（不随 d_model 缩放）
- `N_e` 与 `d_model` 关系：N_e=16 锁定
- 容量因数 4.5x（与原 spec 32x 差异是 N_e 缩小所致）

### 后续 ticket 影响

- A6a-1 (损失函数)：L_sep 公式形式不变，常数 N_e=16 缩放
- A6b-1 (4 阶段)：phase 时长比例不变（1/5/20/30/44%），step count 按 100K 缩放
- A6b-2 (阶段切换触发器)：f_i 阈值从 1/128 改为 1/32（= 1/(2N_e)）；L_sep / WB 阈值按 N_e=16 重算
- A8-1 (Baseline)：6 baseline 全部基于 4070 MVP 配置

### Future Work

- **(F) Fine-grained (DeepSeek 风格)**：N_e=128-256, k=4-8, d_ffn 缩小
- **更大规模**：d_model=2048, N_e=64, L=24+（需要多卡）

### 4. β 退火 Schedule（补充 A3-2 + A6b 输入约束）

- Phase 1: `β_0 ≈ 1.0` (γ ≈ -3.5)
- Phase 2: `β` 渐增
- Phase 3: `β ≈ 16` (γ ≈ +1.4)
- Phase 4: `β` 自由学习（小学习率 projected SGD）
- **A6b 必须显式定义 phase 切换时的 β 调度曲线**（线性 / 余弦 / 阶段阶跃）

### 5. Scaling 关系（Spec 全文遵循）

- `d_ffn` per expert = dense baseline（**不引新超参**）
- `d_c` = 常数 16（不随 d_model 缩放，简化 MVP）
- `N_e` 与 `d_model` 的关系**留作 ablation**（A8 评估时做）
- 容量因数 32x 是 baseline default，spec 允许 ablation override

### 后续 ticket 影响

- A6a-1 (损失函数)：L_lb 作用在 64 个专家上；L_sep 鼓励 c_i 在 S^15 上分散
- A6b-1 (4 阶段)：β schedule 1.0 → 16 与 phase 切换绑定
- A8-1 (Baseline)：对标 Mixtral-8x7B (N=8) / DeepSeek-V3 (N=256) / Dense SwiGLU (1:1)
- A8-2 (几何指标)：θ_Voronoi / θ_1/e / g_boundary 是健康度参考值

### Future Work

- **(F) Fine-grained (DeepSeek 风格)**：N_e = 128-256, k = 4-8, d_ffn 缩小——MVP 后 ablation
- **(A) 联合 scaling**：N_e · d_c · d_ffn 三者联合优化（实验密集型）
