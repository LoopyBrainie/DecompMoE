## Question

跟谁比？baseline set 选什么？

候选 baseline：
- **(D) DeepSeek-MoE**：fine-grained + shared experts，最强 open-source MoE baseline
- **(M) Mixtral**：经典 Top-2 MoE
- **(G) GLaM / ST-MoE**：Google 系 MoE
- **(S) Switch Transformer**：Top-1 MoE
- **(E) 等激活参数 Dense**：控制变量对比（activation FLOPs 相同）
- **(R) Random routing / Uniform routing**：ablation 上界下界
- **(G) GMoE**：高斯门控 MoE，跟我们最直接对比

**关键问题**：
- 评估用同一套数据集还是各 baseline 各自最优？
- 训练 token 数对齐还是总参数对齐？

## Resolution

**锁定：6 个 Baseline（Primary 3 + Direct 1 + Ablation 2），4070 MVP 闭环**

### Baseline 矩阵（4070 闭环，Active ≈ 100M / L = 4）

| 类别 | Baseline | Total / Active | 路由空间 | 验证假设 |
|---|---|---|---|---|
| **Primary (1)** | **(E) Dense SwiGLU** | 100M / 100M | N/A | MoE 稀疏化收益（等激活 FLOPs 基准） |
| **Primary (2)** | **(M') Mixtral 复现** | 250M / 100M | X-空间 Softmax (W_g x) | 经典粗粒度 Token-choice 门控 |
| **Primary (3)** | **(Q1) Qwen1.5-MoE-A2.7B** | 2.7B / 0.8B (QLoRA 压缩至 100M active) | X-空间 Top-4 + 共享专家 | SOTA 开源细粒度范式标杆 |
| **Direct (4)** | **(G) GMoE (Gaussian)** | 452M / 100M | X-空间欧氏距离门控 | **X vs C 空间对比**（关键 insight） |
| **Ablation (5)** | **(R) Random Routing** | 452M / 100M | Uniform 随机选通 | routing signal 有效性下界 |
| **Ablation (6)** | **(S') Random Centroids** | 452M / 100M | C-空间固定随机 c_rand | A3-2 质心拓扑学习的独立贡献 |

### Active FLOPs 严格对齐（核心约束）

| Baseline | Total | Active | d_ffn | 控制机制 |
|---|---|---|---|---|
| Dense SwiGLU | 100M | 100M | **4096** (= 4 × d_model) | 单层 FFN 全开 |
| Mixtral 复现 | 250M | 100M | 2048 | N_e=8, k=2 |
| DecompMoE / GMoE / Random | 452M | 100M | 2048 | N_e=16, k=2 |
| Qwen1.5 (QLoRA 压缩) | 2.7B (官方) | 0.8B → 100M (QLoRA) | 官方 | 量化适配 |

**Active FLOPs 推导**（d_model=1024, L=4）：
- **Dense**: `L · 3 · d_model · d_ffn_dense = 4 · 3 · 1024 · 4096 = 50.4M FFN FLOPs/token`
- **MoE**: `L · k · 3 · d_model · d_ffn_expert = 4 · 2 · 3 · 1024 · 2048 = 50.4M FFN FLOPs/token` ✓
- **1:1 严格对齐**——MoE 激活 FLOPs = Dense 全 FFN FLOPs

### 各类 Baseline 详细规格

**Primary (1) Dense SwiGLU**
- 配置：d=1024, d_ffn=4096, L=4
- Total/Active = 100M/100M
- Embed 32.8M + Attn 16.8M + FFN 50.4M
- **唯一 Non-MoE baseline**——MoE 收益的 control

**Primary (2) Mixtral 复现 (M')**
- 配置：d=1024, d_ffn=2048 per expert, N_e=8, k=2, L=4
- Total = 250M (4 attention + 8 expert × 50.4M/2 + Embed)
- Active = 100M (Embed 32.8M + Attn 16.8M + 2 expert × 25.2M)
- **X-空间 Softmax**：`p = softmax(W_g x)`
- 跟 DecompMoE 同 N_e·k 量级

**Primary (3) Qwen1.5-MoE-A2.7B (Q1)**
- 官方：2.7B total / 0.8B active
- QLoRA 压缩到 100M active 跟本设计对齐
- **X-空间 Top-4 + shared expert**（SOTA 细粒度范式）
- 用途：开放权重标杆对比

**Direct (4) GMoE (G)**
- 配置：d=1024, d_ffn=2048, N_e=16, k=2, L=4
- **X-空间欧氏距离门控**（高斯门控基于输入 x，跟我们基于 C 区别）
- Total/Active = 452M/100M
- 关键 insight：**X-空间 vs C-结构空间**的对比

**Ablation (5) Random Routing (R)**
- 配置：与 DecompMoE 同
- **Uniform 随机选通**——routing signal 完全失效
- 下界：性能不依赖 routing 几何
- 验证 DecompMoE routing signal 的真实贡献

**Ablation (6) Random Centroids (S')**
- 配置：与 DecompMoE 同
- **C-空间固定 c_rand**（c_i 随机但不学习）——A3-2 质心更新被禁用
- 隔离 A3-2 质心拓扑学习的独立贡献（区别于"完全 random routing"）
