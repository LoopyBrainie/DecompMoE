## Question

C 提取和 gating 算子对主流推理 kernel 的友好度：

候选考量：
- **(F) FlashDecoding 兼容**：能不能 batch 多 query 一起算 C
- **(P) PagedAttention 兼容**：C 状态是否要分页存储
- **(M) Memory bound vs Compute bound**：算子是 bandwidth bound 还是 FLOP bound
- **(A) Async / Overlap**：C 提取能否和 attention 计算 overlap

**关键问题**：
- C 状态要不要进 KV cache（增大了多少 per-request memory）？
- 是否需要 custom kernel（CUDA / Triton）？

## Resolution

**锁定：4 项硬件兼容 + 零 custom kernel（MVP PyTorch Eager Mode）**

### 物理参数（存储层级验证）

| 数据 | 大小 | 驻留位置 | HBM 流量 |
|---|---|---|---|
| `W_proj` (W^K, W^V, b) | **~64KB** (BF16) | **100% L2 驻留** | 0 |
| 激活值 (z, ẑ, z̄, C) | **4KB** | **100% SRAM/RF 驻留** | 0 |
| HBM 增量（DecompMoE 引入） | — | — | **0 Bytes** |

**推论**：所有 DecompMoE 相关数据均驻留片上存储，**kernel 优化的边际收益几乎为 0**——直接用 PyTorch 原生算子即可。

### 框架兼容性矩阵

| 框架 | 兼容性 | 物理依据 |
|---|---|---|
| **FlashDecoding** | ✅ | A2-1 锁 Post-FFN 替换，attention 子系统零侵入 |
| **PagedAttention** | ✅ | C_t 在写入 Block 前消费（C 不进 KV cache） |
| **vLLM / TGI / SGLang** | ✅ | FlashDecoding + fused SwiGLU 标准组合 |
| **TensorRT-LLM** | ✅ | kernel 兼容 |
| **Megatron-LM (训练)** | ✅ | DeepSpeed-MoE 兼容 Post-FFN 标准 MoE 范式 |
| **DeepSpeed-MoE** | ✅ | 训练框架兼容 |
| **torch.compile** | ⚠️ 优化路径 | Inductor 可自动融合 4 步原生算子，**MVP 不依赖** |

### Async / Overlap 分析

- C 提取依赖 K_t, V_t（attention 输出）——**必须在 attention 之后**
- Expert FFN 独立于 attention（C_t 已得）——**可与下一层 attention overlap**（pipeline 友好）
- C 提取本身 latency < 0.5% total，不需特殊 overlap 设计

### Custom Kernel 评估

| Kernel | Custom 需求 | 理由 |
|---|---|---|
| Attention | ❌ | 复用 FlashDecoding |
| SwiGLU FFN | ❌ | 复用 vLLM/Megatron/DeepSpeed |
| **C 提取 (L' 投影)** | ❌ (MVP) / ⚠️ (Future Work) | PyTorch matmul + 4KB 激活全在片上，kernel 优化收益极小 |
| 球面归一 (2 次) | ❌ | elementwise L2 norm |
| Logit + Top-k + Softmax | ❌ | PyTorch 原生 |

**MVP 决策：PyTorch Eager Mode + 4 步原生算子**——零 custom kernel。

### MVP 实现路径

```python
# Step 1: per-head projection
z = W_K @ k + W_V @ v + b  # PyTorch matmul

# Step 2: per-head spherical norm
z_norm = z / (z.norm(dim=-1, keepdim=True) + eps)

# Step 3: cross-head mean
z_bar = z_norm.mean(dim=-2)  # over H_kv heads

# Step 4: final spherical norm
C = z_bar / (z_bar.norm(dim=-1, keepdim=True) + eps)

# Routing
logit = beta * (C @ c_i.T - 1)  # [B, T, N_e]
# ... Top-k + Softmax + mixture
```

### Future Work

- **Fused C-Extraction Kernel**：把 4 步算子 fused 成一个 CUDA/Triton kernel——收益 < 5% latency, MVP 不需要
- **Async C 提取 overlap**：把 C 提取 overlap 到 attention 计算中，潜在收益 < 0.5%
- **量化**：W_proj BF16 → INT8 / FP8 进一步省 L2 带宽
- **C 跨层共享**：相邻层 C 可能冗余（spec 复杂，Future Work）
