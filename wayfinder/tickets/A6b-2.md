## Question

阶段切换什么时候触发？

候选：
- **(T) 时间驱动**：`phase 1 → phase 2 @ step X`，固定 schedule
- **(E) 状态驱动**：
  - 专家利用率熵达 plateau
  - C 空间聚类纯度达阈值
  - Task loss 停滞 N 步
  - σ 变化率低于 ε

**关键问题**：
- 纯 T 简单但次优（不同数据需要不同节奏）
- 纯 E 灵活但难调（plateau 判定本身有 magic number）
- 混合策略：T 定 lower/upper bound，E 在区间内决定
- 阶段切换时是否重置 optimizer state（momentum, Adam moments）？

## Resolution

**锁定：3 层混合机制 = Time-Driven 硬切 + State-Driven Advisory + Hard Cutoff**

### Layer 1 — Time-Driven 硬切换（主）

- **切换时刻**：1K → 6K → 26K → 56K → 100K
  - Phase 0: [0, 1K]
  - Phase 1: [1K, 6K] (5K steps)
  - Phase 2: [6K, 26K] (20K steps)
  - Phase 3: [26K, 56K] (30K steps)
  - Phase 4: [56K, 100K] (44K steps)
- **不可被任何信号 override**
- 简单可复现，MVP baseline

### Layer 2 — State-Driven Advisory（只读监控，不自动切）

| 信号 | 定义 | Warning (P1-2) | Warning (P3+) | 物理语义 |
|---|---|---|---|---|
| **归一化熵** `R_H` | `-Σ f_i ln f_i / ln N_e` | `< 0.75` | `< 0.65` | 早期失衡预警 |
| **负载偏斜** `S_load` | `N_e · max_i f_i` | `> 4.0` | `> 6.0` | 单专家过载 |
| **β 饱和** `R_β-sat` | `|{i: β_i > 0.9 β_max(t)}| / N_e` | — | `> 40%` | 退火滞后 |
| **重叠指数** `L_sep / WB` | `L_sep / 0.0476` | — | `> 2.0` | 簇重叠（替代 D_c） |

- 监控频率：每 100 steps
- 触发时：**log warning only**，不自动切换
- 用于 A8 evaluation 阶段分析

### Layer 3 — Hard Cutoff

- `t >= 100K`：强制终止
- 保存最终 checkpoint

### 排除项

- **D_c（c_i pairwise distance）** 不作为实时监控：
  - 计算成本高（O(N_e²) per layer per step）
  - 阈值缺乏严格依据
  - 归入 **A8 离线工具箱**（post-training analysis）

### State 信号物理意义

**R_H 归一化熵**：
- `R_H = 1` 完全均匀
- `R_H = 0` 单专家独占
- `ln N_e = ln 64 ≈ 4.16` 是归一化常数
- P1-2 阈值 0.75: 早期允许较大失衡（exploration 期）
- P3+ 阈值 0.65: 后期 specialist 应更平衡（如果仍失衡说明 routing 没收敛）

**S_load 负载偏斜**：
- `S_load = 1` 完全均匀
- `S_load = N_e = 64` 单专家独占
- 阈值 4.0 (P1-2) / 6.0 (P3+): max f_i 在 4-6% 之间是合理偏斜

**R_β-sat β 饱和**：
- 反映退火是否及时
- >40% 专家接近 β_max(t) 说明 β 退火过慢
- 仅 P3+ 启用（P1-2 β 固定，无意义）

**L_sep / WB 重叠指数**：
- WB = 0.0476 = 软正交损失的自然 baseline
- L_sep / WB > 2.0 说明 c_i 严重聚簇（重叠区扩大）
- 仅 P3+ 启用（与 L_sep 启用同步）

### 阶段切换 optimizer state 处理

| 切换 | optimizer state | 原因 |
|---|---|---|
| P0 → P1 | 不需要（Phase 0 无梯度） | K-Means 不用 Adam |
| P1 → P2 | **保留 Adam 状态** | 同一 optimizer，连续训练 |
| P2 → P3 | 保留 | 同上 |
| P3 → P4 | **重置 c_i 的 Adam 动量** | EMA 状态对 Projected SGD 无效（A6b-1 Phase 4 详述） |
| 其他参数 | 保留 | — |
