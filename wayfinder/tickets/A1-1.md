## Question

定义整个 spec / decision 文档要用的统一符号体系与术语映射。

需要确定：
- 4 个核心张量的最终符号（C, c_i, σ_i 或 Σ_i, w_i）
- 几何术语绑定（"专家领地" = ?, "边界宽度" = σ_i 还是 τ_i 还是别的）
- 传统 MoE 概念到本设计几何空间的映射表（Gate → ?，Capacity → ?, Top-k → ?）
- 是否引入新符号（如 g_i, λ_i, ϕ_i 等）还是复用现有 MoE 符号

## Resolution

### 1. 形式符号 + 退化约定（spec 全文遵循）

- **领地边界形式符号**：`Σ_i ∈ R^{d_c × d_c}`
- **各向同性退化**：`Σ_i = σ_i² · I_{d_c}`，A4-1 选 isotropic 时该约束自动生效
- **优势**：马氏距离 `(C - c_i)^T Σ_i^{-1} (C - c_i)` 在退化情形无缝变成 `||C - c_i||² / σ_i²`，spec 主体 / ADR / Loss 推导全文不需重写

### 2. 工程补充：精度矩阵作为内部优化参量

- `P_i = Σ_i^{-1}`（**Precision Matrix**）作为 spec 内部优化参量
- 避免运行时显式求逆矩阵带来的数值不稳定与算子开销
- 各向同性情形：`P_i = (1/σ_i²) · I`，可分解为标量缩放
- spec 附录明确 `P_i` 与 `Σ_i` 的互换关系

### 3. Subscript 约定

| 符号 | 域 | 物理语义 |
|---|---|---|
| `i` | `1..N_e` | 专家 / Territory Holder 索引 |
| `l` | `1..L` | Transformer 层 |
| `h` | `1..H` | Attention Head（per-head 提取用，聚合后不再 per-head 区分） |
| `t` | `1..S` | 序列位置 |

**符号物理维度（A2-2 修订后）：**
- `C_t^l ∈ R^{d_c}`：第 l 层第 t token 的 KV 结构签名（已 head-aggregated）
- `c_i^l ∈ R^{d_c}`：第 l 层第 i 专家的领地中心
- `Σ_i^l ∈ R^{d_c × d_c}`：第 l 层第 i 专家的领地形状度量矩阵
- `P_i^l = (Σ_i^l)^{-1}`：第 l 层第 i 专家的精度矩阵（内部优化参量）

**A2-2 修订说明**：原 `C_t^{l,h} / c_i^{l,h} / Σ_i^{l,h}` 因 A2-2b 锁 layer-wise head-aggregated，去掉 head 索引 h。per-head 提取 `C_t^{l,h}` 仍发生在 A3-1 阶段，跨 head 聚合后才形成 per-layer `C_t^l`。

**A3-1 修订说明（v2 — RMS 被球面归一化替代）**：C 提取 pipeline 引入 3 个中间量：
- `z_t^{l,h} ∈ R^{d_c}`：per-head 低秩投影输出
- `C_t^{l,h} ∈ S^{d_c-1}`：per-head 球面归一化后（v1 的 `ẑ_t^{l,h}` (RMS) 已被替换为 per-head spherical projection）
- `z̄_t^l ∈ R^{d_c}`：跨 head mean 聚合后（球面内点，未归一化）
- `C_t^l ∈ S^{d_c-1}`：最终球面投影结果，per-layer 签名

**球面归一化贯穿全程**——per-head 归一 → mean → final 归一，两次 L2 保证几何一致。

**A4-1 修订说明（v3 — 球面距离 + 有界 β 参数化）**：gating 几何中心新增参数：
- `γ_i^l ∈ R`：第 l 层第 i 专家的 raw concentration 参数（无约束）
- `β_i^l ∈ [β_min, β_max]`：第 l 层第 i 专家的 concentration（逆温度），`β_i = β_min + (β_max - β_min) · Sigmoid(γ_i)`
- `d(C, c_i) = 1 - C^T c_i ∈ [0, 2]`：球面归一化弦长平方距离
- `logit_i(C) = β_i · (C^T c_i - 1) ∈ [-2β_i, 0]`：路由 Logit

**与原 σ_i 关系**：`σ_i² = 1/β_i`（backward compatible）。原 spec 中 `Σ_i` (领地形状度量) 在 A4-1 各向同性锁定下退化为标量 `σ_i² = 1/β_i`；`P_i = Σ_i^{-1}` 退化为 `1/σ_i² = β_i`。spec 全文使用 β_i 作为主要参数，σ_i 仅在需要时引用。

**A4-2 修订说明（v4 — 彻底剔除 w_i）**：
- 原本设想的 "w_i 独立混合权重" 已被 A4-2 决议**完全删除**
- 混合权重 = `p_i`（Softmax 概率），无需 w_i
- spec 全文不再使用 w_i 符号；A1-1 术语表"Mixture Weight" 行已删除
- A5-2 (共享专家) 必须用不同机制（不能用 w_i 给共享 expert 单独加权）

**A6a-1 修订说明（v5 — 引入 c_i 矩阵符号）**：
- per-layer 全部 expert 中心堆叠为矩阵：
  - `C = [c_1^l, c_2^l, ..., c_{N_e}^l] ∈ R^{d_c × N_e}`
  - 用于 L_sep 软正交损失（A6a-1）
  - 用于球面 Projected SGD 更新规则
- **符号冲突 mark**：`C_t^l ∈ S^{d_c-1}`（per-token, A3-1）vs `C ∈ R^{d_c × N_e}`（per-expert matrix, A6a-1）—— spec 主体靠上下文区分，**写公式时必须明示符号域**

**A6b-1 修订说明（v6 — β_max(t) 分段线性 + 5 阶段编排）**：
- β schedule 不再是简单的 1.0 → 16，而是分段线性函数（phase-dependent）：
  - Phase 1: β = 1.0 (Fixed)
  - Phase 2: β = 1.0 + 3.0 · (t - t_P1_end) / T_P2 (Hard Ramp)
  - Phase 3: β = 4.0 + 12.0 · (t - t_P2_end) / T_P3 (Hard Ramp)
  - Phase 4: β ∈ [1.0, 32.0] (Dynamic Box Bound, free)
- 阶段总表：Phase 0 1% / Phase 1 5% / Phase 2 20% / Phase 3 30% / Phase 4 44% (合计 100%)
- **Phase 4 切换瞬间重置 Adam 动量状态**（EMA 动量对 Projected SGD 失效）
- A6a-2 防御分布：Phase 2 启 Resurrection，Phase 3 启 Loss Spike & Saturation Guard，Phase 4 全部

**A5-3 4070 MVP 修订说明（v7 — 缩小到单卡可跑）**：
- 原 spec：d_model=2048, N_e=64, Total 1.076B, Active 33.62M
- 4070 MVP：d_model=1024, N_e=16, L=4, Total 452M, Active 100M
- d_ffn per expert = 2048 = 2·d_model
- 显存 ~6.8GB (B=1, S=1024)，留 5.2GB 裕度，4070 8GB 可跑
- **球面几何对 N_e=16 仍自洽**（θ_1/e=20.36° < θ_Voronoi≈52°）
- **A6a-1 L_sep 公式形式不变**（常数 N_e 缩放）
- **A6b-2 阈值需重算**：f_i 阈值 1/128 → 1/32（=1/(2N_e)）；L_sep / WB baseline 按 N_e=16 重算

### 5. 后续引用约定

所有后续 ticket / spec / ADR 引用 DecompMoE 符号时：
- 形式上用 `Σ_i^l` / `P_i^l` / `C_t^l`（per-layer，因 A2-2b 锁 layer-wise head-aggregated）
- 退化情形可简写 `σ_i` / `(1/σ_i²)`
- 代码层用 snake_case 命名（`territory_volume` 等）
- 文档层用 PascalCase / Capitalized Phrase（`TerritoryHolder` 等）
