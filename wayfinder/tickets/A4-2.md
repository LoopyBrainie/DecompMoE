## Question

给定 C 和 (c_i, σ_i or Σ_i, w_i)，最终的专家权重如何计算？

候选：
- **(G) Gaussian 软门控**：`g_i = w_i · exp(-D(C, c_i) / (2σ_i²))`，无全局归一化
- **(GS) Gaussian + Softmax**：`g_i = softmax_i({w_j · exp(-D(C, c_j) / (2σ_j²))})`，全局归一化
- **(T) Top-k 截断 + Softmax**：在 G/GS 基础上只保留 top-k 专家
- **(S) Sigmoid 独立激活**：每个专家独立 g_i ∈ (0, 1)
- **(P) Polynomial kernel / RBF 变体**

**关键问题**：
- w_i 是标量权重还是 channel-wise 向量？
- 软混合（全部专家加权）还是硬路由（top-k 截断）？
- Softmax 全局归一化要不要？

## Resolution

**锁定：Top-k 稀疏掩码 + Local Softmax + 纯几何凸组合聚合**

### 1. 彻底剔除 w_i

- A4-1 已定 w_i 不入 Logit
- A4-2 进一步：w_i **完全删除**，不作为 learnable param
- 混合权重 = Softmax 概率 `p_i`（既是 routing signal，也是 mixture weight）
- 简化参数量：每个 expert 省 1 个标量

### 2. 前向公式

```
x_out = x + Σ_{i ∈ I_k} p_i · Expert_i(x)
```

- `I_k`：Top-k logit 索引集合
- `p_i = softmax(logit_j)_{j ∈ I_k}`：local softmax（在 Top-k 集合内归一化）
- `Σ_{i ∈ I_k} p_i ≡ 1.0`：凸组合约束
- Residual 连接保留（A2-1 Post-FFN 替换模式）

### 3. Logit → p_i 的完整路径

```
logit_i = β_i · (C^T c_i - 1)             [A4-1]
masked_i = { logit_i,  if i ∈ top-k(C);  -∞,  otherwise }
p_i = exp(masked_i) / Σ_j exp(masked_j)   [local softmax over I_k]
```

- 掩码用 `-∞`（非 finite 负数）确保 Softmax 输出严格为 0
- 局部归一化：只在 Top-k 上 softmax，其他 i 的 p_i = 0

### 4. 梯度机制：Native Sparse Sub-gradient

- **非 Top-k 专家**：masked logit = -∞ → Softmax 概率 = 0 → **梯度严格为 0**
- **Top-k 专家内部**：标准 Softmax Jacobian，常规 dense 梯度
- **无需 STE**——稀疏性是前向结构带来的，梯度自然 follow

### 5. MVP 配置

- **k = 2**（与 Mixtral 一致）
- 具体 k 与 N_e 的 scaling 关系由 A5-3 决定
- 推理时：Top-k 选择 → 计算 k 个 Expert → 加权求和

### 6. 与 A4-1 边界对齐

- A4-1 定义 Logit；A4-2 定义 Logit → p_i → output 的完整 pipeline
- 没有 w_i 介入，p_i 直接是 routing 概率
