## Question

主损失函数的各项怎么组成？

候选损失项：
- **(L_task) 任务损失**：CE loss
- **(L_lb) 负载均衡损失**：惩罚专家使用频率方差（如 `α · N · Σ(f_i · P_i)`）
- **(L_sep) 领地分离度损失**：惩罚 (c_i, σ_i) 重叠度，鼓励专家专业化
- **(L_z) Router z-loss**：惩罚 router logits 过大值，稳定训练
- **(L_σ) σ 惩罚项**：防 σ 退化为 0 / inf
- **(L_div) 多样性损失**：防止所有 C 映射到同一专家
- **(L_orth) 正交损失**：c_i 之间正交

**关键问题**：
- 哪些项是 mandatory（不训会坍塌），哪些是 optional？
- 各损失项的系数 α 怎么设（固定 / 阶段相关 / 自适应）？
- 与 A6b 阶段切换怎么联动？

## Resolution

**锁定：3 项损失 + 阶段相关 λ schedule**

```
L_total = L_CE + α · L_lb + λ(t) · L_sep
```

### 1. L_CE (Task Loss)

```
L_CE = -Σ_t log p_θ(x_{t+1} | x_{≤t})
```

- 标准 cross-entropy
- 系数 1.0
- 梯度反传至 Transformer 全局（Backbone, Projection, Experts）

### 2. L_lb (Load Balance)

```
L_lb = N_e · Σ_i f_i · P_i
f_i = (1/T) · Σ_t 1[i ∈ Top-k(logits_t)] .detach()   # 无梯度标量
P_i = (1/T) · Σ_t p_i(C_t)                              # 可微概率
```

- α = 0.01（固定）
- **f_i .detach()** —— 指示函数作为无梯度标量权重，梯度只通过 P_i 流动
- 作用于 Router 门控参数 + 提取的 C
- 几何意义：f_i · P_i 最大化 → expert i 被均匀使用

### 3. L_sep (Soft Orthogonality / 领地分离度)

```
L_sep = (||C^T C||_F² - N_e) / (N_e(N_e-1))
```

其中 `C ∈ R^{d_c × N_e}` 是 c_i 矩阵（per-layer 所有 expert 中心堆叠）

- **几何意义**：||C^T C||_F² 是 Gram 矩阵的 Frobenius 范数——正交时 C^T C = I，F = N_e，loss = 0；correlated 时 loss > 0
- **λ(t) 三阶段 schedule**：
  - Phase 1-2: λ = 0（不施压，让 expert 自然分化）
  - Phase 3: Cosine Ramp-up（平滑过渡）
  - Phase 4: λ = 0.001（软稳态）
- 梯度只作用于 c_i（专家中心）
- Phase 4 配合 A3-2 Projected SGD：球面切空间更新

### 4. 梯度公式（球面更新规则）

**欧氏全矩阵梯度**：
```
∇_C L_sep = (4 / (N_e(N_e-1))) · C · (C^T C - I_{N_e})
```

**Phase 4 球面约束更新**（Projected SGD）：
```
C^{(t+1)} = Normalize(C^{(t)} - η · [∇_C L_total])
```

`Normalize(X)` 对矩阵 X 的每一列按 L2 范数归一化至单位长度（保持 c_i ∈ S^{d_c-1}）

### 5. 排除项及理由

- **L_z (Router z-loss)**：A4-1 已证 logit ≤ 2β_max = 64，**有界不需要 z-loss**
- **L_σ (σ 惩罚)**：A4-1 β_min = 0.1 有下界，**不需要**
- **L_div (多样性)**：被 L_lb + L_sep 联合覆盖，**冗余**
- **L_orth (严格正交)**：64 个向量在 R^16 无法严格正交，**不可能**

### 6. 系数原则

- L_CE 主导（系数 1.0）
- L_lb 辅助（α = 0.01）—— 防 collapse 但不主导 routing
- L_sep 阶段依赖（λ = 0 → cosine → 0.001）—— 软约束

### Notation 关键澄清

- **`C_t^l ∈ S^{d_c-1}`**：per-token 结构签名（A3-1）
- **`C = [c_1^l, ..., c_{N_e}^l] ∈ R^{d_c × N_e}`**：per-layer expert 中心矩阵（A6a-1 L_sep）
- 上下文区分：A3 / A4 上下文中 C = per-token；A6a / A6b 上下文中 C = per-expert matrix
