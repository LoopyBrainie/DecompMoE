## Question

C 提取算子（取决于 A3-1 选择）的梯度如何反传到上游（K, V, P）？c_i^l 的更新策略？

候选：
- **(D) 全可微**：选 A3-1=L/M，全链路梯度流通，无 STE 需求
- **(S) Straight-Through Estimator**：选 A3-1=P/F，hard top-k 用 STE 传梯度
- **(E) 无梯度 EMA 更新**：路由中心 c_i 纯靠 EMA 聚类更新（参考 VQ-VAE codebook），不依赖反向传播
- **(H) 混合**：C 提取全可微，c_i 中心走 EMA

**关键问题**：c_i 是"输入空间的离散原型"还是"参数空间的连续变量"？前者更像 VQ-VAE，后者更像普通 embedding。

## Resolution

**锁定：C 提取全可微（D 路径）+ c_i 走 4 阶段生命周期**

### C 提取部分（已被 A3-1 确定）

C 提取 pipeline 4 步全可微（线性投影 + L2 norm 都是 smooth op），**无需 STE**：
- 梯度同时反传到 `W_{l,h}^K, W_{l,h}^V, b_{l,h}` 和上游 K, V
- 球面 L2 norm 在非零点可微（∇C/∂z = (I - CC^T)/||z||），ε 防止 0 点数值爆炸

### c_i 更新策略：4 阶段生命周期（球面几何约束贯穿）

**Phase 0 — Spherical K-Means Seeding**（无梯度）
```
c_i^{(0)} ∈ S^{d_c-1},   i ∈ {1, …, N_e}
```
- 用 1% 数据跑 forward 收集 C 样本
- Spherical k-means 聚类得到 N_e 个 c_i 中心
- 保证初始化点均匀分布 S^{d_c-1}，避免随机初始化

**Phase 1–3 — Masked Spherical EMA**
```
m_i = (Σ_t g_i(C_t) · C_t) / (Σ_t g_i(C_t) + ε),    if Σ_t g_i(C_t) > δ_g
c_i^{(t+1)} = (α · c_i^{(t)} + (1-α) · m_i) / ||α · c_i^{(t)} + (1-α) · m_i||,   else c_i^{(t+1)} = c_i^{(t)}
```

- **加权用 gating 函数 g_i(C_t)**——c_i 由"它当前捕获的 token"驱动
- **死专家保护**：`Σ_t p_i(C_t) > δ_g` 阈值，无 token 路由的专家不更新（避免 0/0）
  - 注：`p_i(C_t)` 取代原 `g_i(C_t)`——A4-2 决议下 p_i 既是 routing 概率也是混合权重，无需 w_i
- **α Schedule**: Phase 1: 0.90 → Phase 2: 0.95 → Phase 3: 0.99（探索快、专精慢）
- **球面 re-normalize**: EMA 混合后立即投影回 S^{d_c-1}，保证 c_i 始终在球面

**Phase 4 — Projected SGD**（Riemannian 梯度下降）
```
c_i^{(t+1)} = (c_i^{(t)} - η · ∇_{c_i} L) / ||c_i^{(t)} - η · ∇_{c_i} L||
```

- 放开小学习率 η，让 c_i 直接优化 routing loss
- 球面投影：每步 gradient 后立即 re-normalize 到 S^{d_c-1}
- 此时专家已分化，c_i 梯度信号稳定

### 鸡生蛋问题解法

| 阶段 | c_i 更新方式 | 解决什么问题 |
|---|---|---|
| Phase 0 | Spherical K-Means | 打破初始化对称性，给专家有意义的起点 |
| Phase 1-3 | Masked Spherical EMA | 抗坍缩，跟踪 C 分布，c_i 与 C 提取解耦 |
| Phase 4 | Projected SGD | 专家分化后让 c_i 直接听 routing loss |

**关键设计**：c_i 在 Phase 1-3 **不接路由梯度**，避免"c_i 朝 routing loss 走 → 全部坍缩到最优点"。Phase 4 才有梯度通道，此时专家已分化。

### 与 A6b 的耦合

- α schedule 与 A6b 阶段切换同步：Phase 1 (α=0.90) / Phase 2 (α=0.95) / Phase 3 (α=0.99)
- Phase 4 启动条件由 A6b-2 决定（状态驱动 vs 时间驱动）
- A6a-1 (损失函数) 必须考虑：c_i 不直接接 routing loss，所以 routing loss 中的 separability 项作用在 (C, c_i) 上而非仅 c_i
