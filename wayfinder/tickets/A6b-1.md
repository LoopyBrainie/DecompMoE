## Question

4 阶段训练 pipeline 的具体排法：

**Phase 0 - 结构预分析**（无梯度）：
  - 跑 1% 数据收集 KV
  - 提取 C 空间分布
  - Spherical k-means 聚类
  - 初始化 c_i, σ_i, 专家

**Phase 1 - 专家独立生存**（router 冻结）：
  - c_i, σ_i, w 全部 freeze
  - 所有专家接收全量数据
  - β_i = 1/σ_i 固定为小值

**Phase 2 - Router 地理学习**（专家冻结）：
  - 只训练 c_i, w
  - σ 保持较大值
  - 目标：c_i 移到数据聚类中心

**Phase 3 - 门控锐化**（专家仍冻结）：
  - c_i, w 继续训练
  - β_i 开始可学习
  - 竞争动力学辅助 β 更新

**Phase 4 - 联合微调**：
  - 全部解冻，小学习率
  - 加入 L_lb 防止坍塌

**决策点**：
- Phase 0 真的需要，还是可以从 random init 直接 Phase 1？
- 每阶段训多少步 / 多少 token？
- c_i 是否走 EMA（VQ-VAE 风格）还是纯梯度下降？

## Resolution

**锁定：5 阶段编排（Phase 0–4） + β_max(t) 分段线性 + Time-Driven 切换**

### 阶段总表（假设 100K steps 总长）

| 阶段 | Steps | 训练 | 冻结 | β | 门控机制 | c_i 驱动 | λ(t) (L_sep) | 关键防御与状态重置 |
|---|---|---|---|---|---|---|---|---|
| **Phase 0** | 1K (1%) | 无（采样） | 全部 | 1.0 (Fixed) | Spherical K-Means | 0 | 聚类质心注入 c_i | — |
| **Phase 1** | 5K (5%) | 专家 FFN | c_i, β_i, W^{K,V}, b | 1.0 (Fixed) | Frozen | 0 | L_lb 纯 Logging（无梯度） | — |
| **Phase 2** | 20K (20%) | c_i, W^{K,V}, b | 专家 FFN | 1.0 → 4.0 (Hard Ramp) | Masked Spherical EMA (α=0.95) | 0 | Dead Expert Resurrection 激活 | — |
| **Phase 3** | 30K (30%) | c_i, β_i, W^{K,V}, b | 专家 FFN | Projected SGD + β_max(t): 4 → 16 | Masked Spherical EMA (α=0.99) | Cosine 0 → 0.001 | Loss Spike & Saturation Guard | — |
| **Phase 4** | 44K (44%) | 全部 (端到端) | 无 | Dynamic Box Bound [1.0, 32.0] | Projected SGD (L2 Re-norm) | 0.001 (Fixed) | 切换瞬间重置 Adam 动量状态 | — |

总计 100K steps，1+5+20+30+44 = 100K ✓

### β_max(t) 分段线性公式

```
β_max(t) = {
  1.0                                    if t ∈ Phase 1
  1.0 + 3.0 · (t - t_P1_end) / T_P2     if t ∈ Phase 2
  4.0 + 12.0 · (t - t_P2_end) / T_P3    if t ∈ Phase 3
  32.0                                   if t ∈ Phase 4
}
```

- **Phase 1**: 1.0 constant（探索）
- **Phase 2**: 1.0 → 4.0 hard ramp（每步线性插值）
- **Phase 3**: 4.0 → 16.0 hard ramp（每步线性插值）
- **Phase 4**: 32.0 上界，β 自由学习（在 [1.0, 32.0] box bound 内）

### β 更新机制：Box-Constrained Projected SGD（Phase 3+）

```python
# 前向
beta_raw = beta_min + (beta_max_global - beta_min) * torch.sigmoid(gamma_i)
beta_i = torch.clamp(beta_raw, min=1.0, max=beta_max(t))  # 动态盒约束

# 反向
# 当 beta_raw < beta_max(t): 梯度正常流经 Sigmoid
# 当 beta_raw >= beta_max(t): clamp 阻断梯度，gamma_i 停止更新
```

- **几何对比**：
  - β 更新：标量空间 Box-Constrained Projected SGD（clamp 在 [1.0, β_max(t)]）
  - c_i 更新：球面 L2 Retraction（gradient step + re-normalize）
- **共享"投影约束"数学框架**（constrained optimization on manifold），但几何不同
- **Box constraint** 阻断梯度时 γ_i 停止更新（自然 dead-zone），避免 β 进一步饱和

### 各阶段详细动作

**Phase 0 (1K steps, 1%)** — Spherical K-Means Seeding
- 跑 1% 数据收集 C_t^l 样本
- Spherical k-means 聚 N_e = 64 类
- 初始化 c_i = 簇中心, β_i = 1.0
- 无梯度

**Phase 1 (5K steps, 5%)** — 专家独立生存
- 训练：W^g, W^u, W^d（专家 SwiGLU FFN）
- 冻结：c_i, β_i, W^K, W^V, b
- 损失：仅 L_CE；**L_lb 纯 Logging 无梯度**（避免 routing 干扰专家学习）
- β = 1.0（宽门控）

**Phase 2 (20K steps, 20%)** — Router 地理学习
- 训练：c_i (via masked spherical EMA), W^K, W^V, b
- 冻结：专家 W^g/W^u/W^d
- 损失：L_CE + 0.01·L_lb（λ=0）
- β: 1.0 → 4.0 hard ramp
- **Dead Expert Resurrection 激活**（early detection & 修复）

**Phase 3 (30K steps, 30%)** — 门控锐化
- 训练：c_i (EMA 0.99) + β_i (Projected SGD, β 自由学习)
- 冻结：专家
- 损失：L_CE + 0.01·L_lb + λ(t)·L_sep（cosine ramp 0 → 0.001）
- β: 4.0 → 16.0 hard ramp（β_max(t) 控制）
- **Loss Spike Defense 启用**（A6a-2 ⑤）
- **β Saturation Guard 启用**（A6a-2 ④）

**Phase 4 (44K steps, 44%)** — 联合微调
- 训练：全部（小学习率）
- c_i via Projected SGD（球面 L2 re-norm）
- β 自由学习（[1.0, 32.0] box bound）
- 损失：完整 L_total
- λ = 0.001 (Fixed)
- **Phase 4 切换瞬间重置 Adam 动量状态**（EMA 状态对 Projected SGD 无效）
