## Question

用什么指标监控"几何演化是否健康"？

候选指标：
- **(SI) Separability Index**：监控 (c_i, σ_i) 重叠度
- **(E) 空间熵**：c_i 在 C 空间中的分布是否均匀
- **(C) 坍缩度**：所有 c_i 距离质心的方差
- **(SP) Specialization Purity**：每个专家处理的 token 在真实任务上的纯度（如某个专家专攻"数字 token"）
- **(UR) Expert Utilization Rate**：专家使用率分布
- **(CG) C 空间梯度范数**：监控 C 提取算子是否在更新

**关键问题**：
- 哪些是训练时实时监控，哪些是最终评估？
- 指标的"健康范围"怎么定（什么算坍缩、什么算健康、什么算过分离）？

## Resolution

**锁定：8 个指标分 2 类（4 实时 + 4 离线）**

### 实时监控（4 个，每 100 step）

| 指标 | 公式 | 正常 | 警戒 | 病态 |
|---|---|---|---|---|
| **L_sep** | `(1/(N_e(N_e-1))) · Σ_{i≠j} (c_i^T c_j)²` | < 0.05 | 0.05-0.15 | > 0.30 |
| **R_H** | `-Σ f_i ln f_i / ln N_e` | > 0.85 | 0.65-0.85 | < 0.65 |
| **S_load** | `N_e · max_i f_i` | < 2.0 | 2.0-4.0 | > 6.0 |
| **UR** | `f̄_i^(100)` (100 step 滑动平均) | > 1/32 | — | < 1/32 (触发 Resurrection) |

**L_sep 等价形式**（与 A6a-1 旧式等价）：
- 新式：`L_sep = (1/(N_e(N_e-1))) · Σ_{i≠j} (c_i^T c_j)²`
- 旧式：`L_sep = (||C^T C||_F² - N_e) / (N_e(N_e-1))`
- 数学等价：c_i 单位范 ⇒ Σ_i ||c_i||² = N_e ⇒ Σ_{i≠j} (<c_i, c_j>)² = ||C^T C||_F² - N_e

**L_sep 健康范围**（N_e=16）：
- 随机均匀 c_i 在 S^15：E[L_sep] = 1/d_c = 1/16 = 0.0625
- 健康 < 0.05 表示 c_i **比随机更分散**（good）
- 病态 > 0.30 表示 c_i 严重聚簇

### 离线分析（4 个，Post-Training）

| 指标 | 公式 | 用途 |
|---|---|---|
| **SP** | `mean_{t ∈ T_i} (c_i^T C_t)` | 专家-数据对齐度 |
| **D_c** | `sqrt(2(1 - c_i^T c_j))` | 质心散布矩阵（球面 geodesic 距离） |
| **MCI** | `1 / (d_c · Σ λ_j²)` | **有效维度占比**（替代 CV） |
| **CG** | `\|\|∇_{W^{K,V,b}} L\|\|_2` | Debug only |

**SP 特化纯度**：
- T_i = tokens routed to expert i
- 范围 [0, 1]，高 = 专家 c_i 与其 assigned token 的 C 中心对齐
- 健康：mean(SP_i) > 0.6

**D_c 散布矩阵**：
- 球面 geodesic 距离（不是欧氏距离）
- `D_c(i, j) = sqrt(2(1 - <c_i, c_j>)) ∈ [0, 2]`
- 用 spherical geometry 而非欧氏，正确反映 S^{d_c-1} 上的距离

**MCI 参与比（替代 CV）**：
- λ_j = C 分布协方差矩阵的特征值
- `effective_dim = 1 / Σ (λ_j/Σ λ)²`
- `MCI = effective_dim / d_c`
- **大值 = C 在 S^{d_c-1} 上分布广（good）**
- **关键修正**：原 CV（C 分布凸包半径）在 S^{d_c-1} 下界为 1/d_c = 0.0625（健康值不可达），故替换

**CG 梯度范数**：
- 监控 C 提取算子是否正常更新
- 异常：突然消失（学习停滞）/ 爆炸（数值不稳定）
- 仅 Debug 用，不进 spec 主指标体系

### 关键修正（用户补充）

- **CV (C Volume Radius) 不可用**：单位球面约束下，C 分布"凸包半径"下限为 1/d_c，原设计 "< 0.05 健康" 不可达
- **改用 MCI**：方向一致（越大越健康），且数学上无下界问题

### 指标健康度总表

| 指标 | 公式 | 健康方向 | 健康参考 |
|---|---|---|---|
| L_sep | c_i 散布 | 低 | < 0.05 |
| R_H | 利用均匀 | 高 | > 0.85 |
| S_load | 负载偏斜 | 低 | < 2.0 |
| UR | 专家使用 | 中 | 接近 1/16 = 0.0625 |
| SP | 专家-数据对齐 | 高 | mean > 0.6 |
| D_c | 质心散布 | 中 | 反映"是否聚簇" |
| MCI | 有效维度占比 | 高 | > 0.7 (理想) |
| CG | C 梯度范数 | 稳定 | 监控异常 |

### 阶段监控映射

| 阶段 | 关键监控 | 关注指标 |
|---|---|---|
| Phase 1 | 专家是否分化 | R_H, UR |

| Phase 4 | 终态几何健康度 | 全部 8 指标 |
