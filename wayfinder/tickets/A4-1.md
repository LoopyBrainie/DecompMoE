## Question

用什么距离度量定义"专家领地"？

候选：
- **(I) 各向同性 (Isotropic)**：`D = ||C - c_i||₂`，标量 σ_i 控制球形边界。**简单、参数少、训练稳定**
- **(A) 各向异性 (Anisotropic)**：马氏距离 `D = (C - c_i)^T Σ_i^{-1} (C - c_i)`，Σ_i 矩阵描述椭球形状。**灵活但参数 + 训练难度上台阶**
- **(C) 协方差 Cholesky**：Σ_i = L_i L_i^T，保证正定

**决策点**：本设计的终态是球形领地还是椭球领地？原版 C-σ 设计是球形，要不要扩展？

## Resolution

**锁定：各向同性归一化弦长平方度量 + 有界浓度参数化 + 对数空间 Logit**

### 1. 空间度量（球面归一化弦长平方）

```
d(C, c_i) = 1 - C^T c_i  ∈ [0, 2]
```

- 几何意义：球面 S^{d_c-1} 上 C 与 c_i 的**归一化弦长平方**
- 与 Euclidean 距离关系：`d = (1/2) · ||C - c_i||²`
- 范围 [0, 2]：`d=0` 当 C = c_i；`d=2` 当 C = -c_i

### 2. 浓度参数 β_i（有界 Sigmoid 参数化）

```
β_i = β_min + (β_max - β_min) · Sigmoid(γ_i)
```

- 默认 `β_min = 0.1, β_max = 32.0`
- **learnable raw param 是 γ_i ∈ R**（无约束），通过 Sigmoid 映射到有界区间
- 物理意义：`β_i = 1/σ_i²`（与原 σ_i 设计 backward compatible：`σ_i² = 1/β_i`）
- **β 有界 ⇒ 数值稳定 + 梯度有界**（见下）

### 3. 路由 Logit（对数空间）

```
logit_i(C) = -β_i · d(C, c_i) = β_i · (C^T c_i - 1)  ∈ [-2β_i, 0]
```

- 范围 [-2β_i, 0]：`logit=0` 当 C = c_i；`logit=-2β_i` 当 C = -c_i
- 形式干净，可直接喂 softmax / top-k / Gumbel-Softmax

### 4. 初始化

- `γ_init ≈ -3.5` → `β_0 ≈ 1.0`（Phase 1 宽门控探索）
- 与 A6b 退火调度配合：Phase 1 宽 → Phase 4 紧

### 5. 数值稳定性保证（梯度完备上界）

| 梯度项 | 上界 |
|---|---|
| `||∂logit/∂C||_2` | `≤ β_max = 32.0` |
| `|∂logit/∂γ_i|` | `≤ 0.5(β_max - β_min) = 15.95` |
| `||∂logit/∂c_i||_2` | `≤ β_max = 32.0` |

- **无 exp(-D) 下溢**（logit 是 log 空间，未求 exp）
- **无 σ^(-3) 梯度爆炸**（β 有界，且 Sigmoid 平滑）
- **无 arccos 奇点**（直接 dot product，无反三角）
