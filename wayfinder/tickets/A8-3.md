## Question

用什么工具可视化高维 C 空间和专家领地的演化？

候选：
- **(U) UMAP**：保留全局结构，可视化 c_i 移动轨迹
- **(T) t-SNE**：保留局部结构
- **(P) PCA**：3D 投影
- **(A) 动画**：训练过程中 c_i 移动的动画
- **(H) Heatmap**：c_i pairwise 距离矩阵随 step 变化
- **(V) Voronoi 图**：2D 投影下专家领地的 Voronoi 划分

**关键问题**：
- 可视化是给 spec 配图用（静态截图）还是给训练 dashboard 用（动态更新）？
- 是否需要交互式可视化（plotly / streamlit）？

## Resolution

**锁定：6 个可视化模块，全部 production-ready spec**

### 可视化模块矩阵

| 模块 | 实现库与关键 API | 核心参数/代码约束 | 产出物用途 |
|---|---|---|---|
| **3D PCA 静态** | `sklearn.decomposition.PCA` + `mpl_toolkits.mplot3d` | 固定 `elev=25, azim=135`，按 Layer 着色 | Paper 拓扑散布主图 |
| **D_c 热力图** | `matplotlib.pyplot.imshow` + `scipy.cluster.hierarchy` | 执行 **Optimal Leaf Ordering** 矩阵重排 | Phase 演化 Snapshot |
| **2D Voronoi** | `scipy.spatial.Voronoi` + `matplotlib.patches.Ellipse` | 特征值缩放椭圆拟合 β 门控边界 | 领地锐化对比图 |
| **轨迹动画** | `matplotlib.animation.FuncAnimation` + `imageio` | **固定 Phase 4 投影矩阵 W_PCA** | 训练过程动态 GIF/MP4 |
| **实时 Dashboard** | `torch.utils.tensorboard.SummaryWriter` | 挂载 `L_sep, R_H, S_load, f̄_i^(100)` | 实时训练监控 |
| **文档架构图** | plantuml (CLI / VS Code Plugin) | 源码内嵌 `.puml`，编译导出 SVG | Spec 文档架构与状态机 |

### 关键约束详解

**3D PCA 固定视角**：
- `elev=25, azim=135`——保证 paper 配图可重现，不依赖运行时视角
- 按 Layer 着色——4 层（l=1,2,3,4）不同颜色，看出 c_i^l 跨层结构

**D_c Optimal Leaf Ordering**：
- `scipy.cluster.hierarchy.dendrogram` 排序 c_i
- 让相似的 expert 在矩阵中相邻
- 热力图可读性 ↑↑

**2D Voronoi + 椭圆双重可视化**：
- Voronoi 边界（硬划分）+ 椭圆（β 门控软覆盖）
- 椭圆轴长：`a = 1/√β_x, b = 1/√β_y`（特征值缩放）
- 双重对比：硬划分 vs 软覆盖的差异

**轨迹动画固定 W_PCA**：
- 训练全程 c_i 投影用 Phase 4 末的 `W_PCA ∈ R^{d_c × 2}` 矩阵
- 避免训练过程中投影矩阵变化导致轨迹失真
- 关键观察点：Phase 切换时的 c_i 跳跃（K-Means init, EMA 切换, Projected SGD）

**TensorBoard 实时挂载**：
- `L_sep`: 领地散布
- `R_H`: 利用均匀度
- `S_load`: 负载偏斜
- `f̄_i^(100)`: 100 step 滑动使用率

**plantuml 文档架构图**：
- Spec 文档用 plantuml 画架构图 + 状态机
- 源码内嵌 `.puml` 编译 SVG（version control 友好）
- 用于：4 阶段状态机、DecompMoE 整体架构、C 提取 pipeline

### 排除项

- **(U) UMAP / (T) t-SNE**：
  - 16-dim 数据 UMAP/t-SNE 收益有限
  - 速度慢、可解释性差
  - 留 Future Work
- **3D plotly interactive**：
  - paper 不需要
  - 留 exploration 工具

### 阶段产出物时间线

| 阶段 | 输出 |
|---|---|
| Phase 0 末 | Voronoi (init c_i 分布) + D_c Heatmap |
| Phase 1 末 | PCA 3D (专家 init 状态) |
| Phase 2 末 | Animation 增量 + D_c Heatmap |
| Phase 3 末 | Animation 完整 + Voronoi (β 收紧) + D_c |
| Phase 4 末 | 全部 + Final Paper 配图（PCA + Voronoi + D_c） |
| 训练全程 | TensorBoard dashboard |
