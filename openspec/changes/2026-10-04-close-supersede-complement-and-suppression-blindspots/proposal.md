# 关闭 `superseded by` 补语豁免与剩余的整行抑制盲区

## Why

上一轮 `2026-10-03-close-exemption-collision-and-detector-integrity` 修好了「豁免按整行判定」这个根因，归档后独立复核仍判定 **FAIL**。复核的结论经逐条独立复现，**全部成立**。

最重的一条（H1）直接否定了上一轮的收口声明：

上一轮把 `;` 从断点字符里移除，理由是本仓的规范注解
`(historical, <值>; superseded by spec req-N L### via <change> Decision M)`
是**被分号隔开的一个单位**，断开它会把九个正当历史注解报成活指针。

这个理由对**票据自身的陈述**成立，对**同一行里的 spec 定位符**不成立。`historical` 标注的是**票据**；`superseded by spec req-20 L453` 命名的是**当前的权威文本**——而后者恰恰就是会漂移的那类指针。让标记跨过分号伸进 `by` 补语，结果是：

| 被豁免的定位符 | 实际偏差 |
|---|---|
| `req-11 L204`（A1-1:98、A5-3:63） | 指向**空行**，`req-11` 锚在 L247，偏 43 行 |
| `req-7 L122`（A4-1:59） | 落在上一个 Requirement 的 Scenario，`req-7` 锚在 L136 |
| `req-13 L268`（A6a-2:63） | 内容完全无关（"No Q/K/V/O biases"），`req-13` 锚在 L329，偏 61 行 |
| `req-14 L321`（A6b-1:1、:14） | 落在上一个 Requirement 的 Scenario，`req-14` 锚在 L353 |
| `req-20 L453`（A8-2:70、:74） | 指向**空行**，`req-20` 锚在 L462 |

**9 处，占当时 14 个「站点」中的 9 个。** 上一轮清扫了 14 处**未被标记**的指针，把这 9 处留给了标记，普查因此报 0 actionable。收口是循环的：普查在一个「主导指针形态本身已偏移 30–60 行」的总体上宣告干净。

另有三条同族缺陷，全部在门禁全绿的情况下存在：

- **`RE_LABEL_L` 抑制整行。** 行内任何位置出现 `L2-step2` 这类标签，`scan_line` 直接 `return sites`。同一行上其余所有指针一并消失。**这与本 change 要消除的行级抑制是同一条规则。**
- **未闭合的反引号 / fence。** 掩码在找不到同长度闭合段时只标记定界符，body 漏给标记器：`` ```python HISTORICAL=True  # wayfinder/spec.md L83 `` 中 `HISTORICAL` 成了有效标记。
- **`dedupe` 让 historical 实例遮蔽 live 实例。** `(historical: spec.md L83) -- 但 spec.md L83 是当前的`：三个站点同键，`hist` 那个按 kind rank 胜出，两个活的从普查里消失。

以及三条使「零」变得比看上去更脆弱的缺陷：

- **`if found:` 包裹了基线段全部实质检查。** `scan_commit` 返回 `[]` 时门禁 exit 0、报「DETECTOR FIT」、少跑 6 项而无任何提示。上一轮宣称「基线不可读 → FAIL，不再 SKIP」——那只对**异常**成立，对**空结果**仍是静默跳过。
- **`EXEMPT_BREAK = "。\n"` 是空转的。** `scan_line` 是逐行的，`\n` 永不出现；英文句号不在集合里。`was \`1/128\`. now spec req-20 L453` 跨句号保持豁免。
- **裸 hex 词被当作 pin。** `defaced` / `effaced` / `deadbeef` 都是 7 位纯 `[0-9a-f]` 词，各豁免一处活指针——与 D3 声称已修好的 `history` 名词同一类。

## Scope

- `scripts/pointer_scan.py` — `superseded by` 补语规则、标签抑制、掩码未闭合分支、dedupe 裁决、句读断点、中文旧时态、裸 hex。
- `scripts/lint_pointer_detector.py` — 空基线判负、已执行检查数断言、普查范围断言。
- `tests/test_pointer_scan.py` — 每个新缺陷形态一例（10 项），并改写上一轮那条断言旧行为的测试。
- `openspec/specs/governance/spec.md` — 1 处（1 份 delta）。
- `wayfinder/tickets/**` — 9 处（票据注解不产生 spec delta）。

## What Changes

1. **`superseded by X` 中的 X 不再可被豁免。** 新增 `RE_SUPERSEDE_LEAD`；`_exempt` 先判断站点是否落在某个 `superseded by` 的补语内，是则直接不豁免。理由可从语法推出：`by` 补语就是被取代者，即**现在**，引入它的那个词不可能对它做出关于过去的陈述。
2. **`RE_LABEL_L` 只抹标签，不抹整行。** 用等长空格替换以保持每个字符偏移不变——`Site.pos` 与豁免窗口都以该串为基准。
3. **掩码的未闭合段标记到行尾。** CommonMark 把未配对反引号读作字面量，那是对「更严格」的读法，但对门禁是**错的方向**：未闭合的 fence 是排版事故，放行其 body 等于让代码里的词当标记。
4. **`dedupe` 以「活」优先。** 同一 locator 只要有一处是活的，就报为活。
5. **句读断点改为正则** `[。！？]|[.!?](?=\s|$)`，并只保留**包含站点**的那一段窗口。不能直接把 `.` 放进断点字符集：本语法里每条路径都带点，`safeguards.py:40`、`1.128` 会让窗口在文件扩展名处被截断，从而对所有路径形态指针静默关闭豁免。
6. **中文旧时态补齐** `旧`/`之前`/`曾`/`当时`；`原` 单字在本中文为主的仓库里是不一致而非决定。
7. **移除裸 hex 标记。** pin 必须被**明说**为 pin（`RE_PIN_COMMIT` 要求 `commit` 一词），其余不需要这条。
8. **门禁**：空基线判负；报告并断言已执行检查数（`MIN_CHECKS = 45`）；普查范围断言改为「构成」而非「总数」——682 个 tracked 文件中 594 个在 `openspec/changes/archive/` 下按设计排除，**80 才是正确数字**，`> 500` 是在算出数字之前写的断言，等于把一个排除项当成正确性要求。
9. **清扫 9 处 `req-N L###`**，改为 Requirement 锚点（`req-20 L453` → `req-20-mci`，更精确）。
10. **1 处更深的指错**：`governance:145` 的 `req-1 L184-L185` —— L184-185 实际落在 `req-8`（Top-K Sparse Mask）内，而 `req-1` 是 Naming And Alias，与 k=2 路由无关。替换时把原 id 保留在文本里，不静默抹掉记录。
